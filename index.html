AC101 — Management Accounting and Data-Driven Decision Making

Part 1: Using Cost Information for Decisions

Welcome

This course teaches you how managers use cost information to make decisions. You’ll work with Tesla’s actual filings to build analytical skills that consultants and managers use every day.

By the end of Part 1, you will have built a complete cost analysis of Tesla’s manufacturing operations — not by watching, but by doing. The week is also written up as one integrated case, Five Days at Fremont: What Does a Tesla Really Cost? — worked in the room, one part per session; the full case is posted after Session 5 as the exam-revision companion.

The Journey

1 What does it cost to make a Tesla? Cost classification map

How This Works

Each session combines:

  • Concepts — the “why” before the “how”
  • Techniques — the analytical tools
  • Hands-on analysis — you run the code, interpret the results

You don’t need to know Python. The notebooks are pre-written. Your job is to:

  1. Run the code cells
  2. Interpret what the output means
  3. Make decisions based on the analysis

Getting Started

Option 1: Google Colab (Recommended)

No installation needed. Click the “Open in Colab” button on any notebook.

Option 2: Local Python

If you prefer working locally, install Python 3.11+ and four packages. Pick your system:

NoteWindows
  1. Install Python from python.org/downloads — on the first installer screen tick “Add python.exe to PATH”.
  2. Open PowerShell and run:
pip install pandas numpy matplotlib scipy jupyter
  1. To open a notebook: jupyter lab (a browser tab opens; drag the .ipynb file in).
NotemacOS
  1. Install Homebrew if you don’t have it, then in Terminal:
brew install python
pip3 install pandas numpy matplotlib scipy jupyter
  1. To open a notebook: jupyter lab.
NoteLinux 
sudo apt install python3 python3-pip   # Debian/Ubuntu
pip3 install pandas numpy matplotlib scipy jupyter

Then jupyter lab to open notebooks.

Either way, Colab needs none of this — it runs in the browser.

The Data

We use Tesla as our primary case throughout Part 1. The data comes from:

  • Tesla’s 10-K and 10-Q filings on SEC EDGAR
  • Production and delivery reports from Tesla Investor Relations
  • Internal cost breakdowns — simulated from industry benchmarks, clearly labelled
